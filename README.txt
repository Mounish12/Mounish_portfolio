HOW TO ADD YOUR REAL FILES
1. Put each certificate's image preview in images/ using the exact filename shown above.
2. Put the corresponding PDF in certificates/ using the exact filename shown above.
3. If you use different names, update the matching src and href in index.html.
4. Open index.html in a browser to test it.
5. When publishing, upload index.html AND both folders. Relative links will then work online.

IMAGE TIP
For a PDF certificate, you can take a clear screenshot or export one page as JPG/PNG for the preview. Keep the full PDF in certificates/.
The sample image/PDF files are not included because your real certificates were not provided. Until you add them, the page displays a placeholder preview and the PDF links will not open.

PRIVACY
Only publish certificates you are comfortable sharing publicly. Hide sensitive ID numbers, signatures, or personal details where appropriate.
